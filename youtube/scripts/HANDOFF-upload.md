# 引き継ぎ：YouTube「らくがき経済」の予約投稿

## やってほしいこと
YouTube Studio で、下のスケジュールどおりに動画を予約投稿する（ブラウザを操作して）。

## 中身のありか
- GitHub：xxxainumaxxx-hash/sonae-navi のブランチ `claude/youtube-channel-idea-63szhv`
- スケジュール：`youtube/scripts/schedule.md`（日付・時刻・どの動画か）
- タイトル・説明文・ハッシュタグ：`youtube/scripts/descriptions-<会社>.md`（nintendo / toyota / sanrio / honda / asics）
  - 「タイトル」の行がタイトル、``` で囲まれた部分が説明文（そのまま貼る）
  - （リンク）（本編のリンク）（メールアドレス）は、公開後に埋める／わからなければ空欄の行ごと消してよい
- 動画ファイルとサムネイルは GitHub には入っていない。ユーザーがパソコンの1つのフォルダに保存している（ファイル名は schedule.md の「ファイル」の列と同じ名前）

## 予約のしかた
1. YouTube Studio →「作成」→「動画をアップロード」
2. タイトル・説明文を貼る
3. 本編はサムネイルA（thumbnailA.png）を設定。「テストと比較」が使えれば B・C も入れる
4. 子ども向けではない／公開設定「スケジュールを設定」で schedule.md の日時（日本時間）
5. ショートは、同じ会社の本編が公開された後に出る順になっている。ショートの「関連動画」に本編を設定する（本編がまだ予約中で選べなければ、公開後に設定する）

## 決まりごと
- 返事は日本語だけ、やさしい言葉で
- 本編：火・金 19:00、ショート：ほかの日 18:00（毎日1本、11/13〜12/3）
- 11/13 19:00 の任天堂本編は、ユーザーが自分で入れている場合がある。先に YouTube Studio で確かめる
