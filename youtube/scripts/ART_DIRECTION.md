# 映像づくりのルール（スカスカ対策）

任天堂の試作を見たフィードバック：**背景に対して要素が少なく、スカスカに見える。飽きる。**
次から作る映像はすべて、このルールで作る。

## 1. 大きく・アップで見せる
- 主役（人物・モノ）は**画面の高さの半分以上**の大きさにする。小さく真ん中にぽつんと置かない。
- 1場面の中で、**引き → 寄り**を必ず入れる（例：お店の全体 → 職人の手元のアップ）。
- 大事なセリフのときは、**顔のアップ**に切りかえる（驚く・困る・ひらめく顔）。
- 数字や結論は、**画面いっぱいの大きな文字**で見せる。

## 2. 常に何かが動いている
- **2〜3秒ごとに新しい動き**を入れる（登場・ズーム・パン・物の動き・表情の変化）。
- 止まった絵が3秒以上続かないようにする。
- 人物は話していなくても動かす：うなずく、体をゆらす、まばたき、手を動かす、歩く。
- カメラも動かす：ゆっくりズーム、横パン、驚いた瞬間にグッと寄る、ショックのときに画面をゆらす。
- 物は落ちてくる・飛んでくる・はねる・回る・積み上がる。ポンと出すだけで終わらせない。

## 3. 背景に色と場所をつける
- **単色ベタの背景は禁止**。最低でも次のどれかを入れる。
  - 場所の背景：部屋（壁・床・窓・家具）、町並み、工場、お店、空と地面、夜空
  - 色のグラデーションや、光の当たり方（スポットライト・夕焼け）
  - 奥の小物：壁のポスター、棚、時計、植物、看板
- **場面ごとに背景の色を変える**（時代やムードで：昔＝セピア、ピンチ＝暗い青、成功＝明るい黄色）。
- 手前・真ん中・奥の**3つの層**を作る（奥の背景、真ん中の主役、手前の小物）。

## 4. 画面の密度
- 1画面に、**主役1つ＋脇役2〜3つ＋背景**を目安にする。
- 画面の**左右の端まで使う**。真ん中だけに集めない。
- 空いたスペースは、背景の小物・効果線・キラキラ・吹き出し・看板で埋める。
- ただし、字幕の場所（ロングは下から約190px、ショートは下から560px）と、ショートの右下のボタン列には物を置かない。

## 5. 飽きさせない工夫
- 同じ構図を続けない。場面が変わるたびに、**カメラの位置や大きさを変える**。
- 場面の切りかえに変化をつける：ワイプ、ズームで飛びこむ、紙がめくれる、など。
- ちょっとした小ネタ（すみっこのネコなど）を、ロングにも時々入れる。

## 作るときのチェック
- [ ] 主役が画面の半分以上ある
- [ ] 背景が単色ベタになっていない
- [ ] 3秒以上止まった絵がない
- [ ] 各場面に、少なくとも1回はアップか寄りがある
- [ ] 字幕と看板がかぶっていない

## 決まっていること（メモ）
- **作る順番**：台本 → 声 → 絵。声と一緒に「どの文字を何秒に読んだか」のデータ（ElevenLabs の with-timestamps）を取り、言葉と絵のタイミングをぴったり合わせる。
- **チャンネルの声（ロングもショートも共通）**
  - 声：Otani（voice_id `3JDquces8E8bkmvbh6Bc`）
  - モデル：eleven_v3
  - 後処理：文と文の間を約0.25秒まで詰める → 1.35倍速（音の高さは変えない）
    - ffmpeg: `silenceremove=start_periods=1:start_threshold=-40dB:stop_periods=-1:stop_duration=0.25:stop_silence=0.25:stop_threshold=-40dB,atempo=1.35`
  - 速さの目安：約7字/秒。**ロング台本は3,800字以上**（8分を切らないため）。
  - しんみりした場面だけ、間を少し長めに残す調整もあり。
- 数字・人名は聞き取りにくくなるので、画面に大きく文字を出して補う。
- ElevenLabs のAPIキーは環境に登録済み。

## 参考動画から学んだこと（Crayon Capital「How Steve Jobs Actually Built Apple」の画面収録18秒を分析）
1. **カットは2〜3秒ごと。** 18秒で6カット（丘の2人 → ロゴ → 章タイトル → 2人のアップ → 新聞 → コンピューター）。
2. **カメラは止めない。** どのカットも、ゆっくり下へ・寄る・横へ流れる、のどれかが動いている。
3. **人物はアップで大きく。** 2人の顔が画面の高さの4割くらい。体が画面の端で切れてもよい。
4. **場面のつなぎ方を工夫する（ただのカットにしない）。**
   - 形でつなぐ：丘の形 → そのままロゴの形に変わる
   - 引いてつなぐ：2人の絵 → カメラが引くと新聞の写真になっている（絵の中の絵）
   - 手前を横切ってつなぐ：大きな人の頭が手前を横切り、その間に次の場面へ
5. **文字の演出は少なく、効果的に。**
   - 章の区切り：黒い画面に小さな文字の章タイトル（約2秒）
   - 大事な言葉に、蛍光ペンで線を引くアニメ
   - 物の名前は、1文字ずつ打たれて出てくる（タイプライター風）
   - それ以外は文字に頼らず、絵で見せる
6. **背景は白にしない。** くすんだ色（紫がかったグレー、茶色の机、紺）で塗り、家具や機械を描き込む。
7. このチャンネルは、YouTube の自動吹き替え（多言語の音声）を使っている。日本語の視聴者にも届いている。

→ 絵柄はクレヨンのまま、**撮り方（カメラ・カット・つなぎ方・文字の出し方）を取り入れる。**

### 参考動画2：「How Jeff Bezos Actually Built Amazon」（Claude in Chrome で分析）
- **カットの間隔**：冒頭20秒は1.5〜3秒（ナレーションの1フレーズに1カット）。本編は2〜4秒。図解・地図だけ4〜6秒。
- **カメラ**：ゆっくりズームインが基本。全体を見せるときはズームアウト（州のアップ → アメリカ全体）。縦のパンで次の場面へ移る（店の場面 → 下のサーバーラックへ降りる）。手ブレのような揺れは使わない。
- **人物の大きさ**：バストアップが中心で、**画面の高さの60〜90%**。顔のアップ、肩越しのショットも。物も画面の半分以上。全身や遠景は場所の説明カットだけ。
- **背景**：場面ごとに色をはっきり変える（夜＝紺、病院＝水色の空、事業計画＝黄色のスポットライト、地図＝緑）。人物の後ろは単色やぼかしでもよい。
- **つなぎ方**：基本は普通のカット。そこに左右分割のワイプ、パンでの移動、黒や単色の画面に文字だけの間（「30 years later」や章タイトル）を混ぜる。最後は暗転。
- **文字**：手書き風の文字で、数字や地名を1文字ずつ出す。セリフは白い吹き出し。要点は丸で囲み、年号は付箋。地図は札とピンで順番に。

### 参考動画3：「5歳児でもわかるNVIDIAの解説」（Claude in Chrome で分析）／2本の比較
- 2本とも同じ型：カット2〜4秒、人物は画面の高さの60〜90%、ゆっくりズーム、揺れなし、強調語だけ絵として出す。
- **会社のブランドカラーに合わせて、全体の配色を変える**（NVIDIA＝黒〜深緑）。任天堂なら赤×白、トヨタなら赤×グレー、など。
- 冒頭のつかみは**約2秒ごと、数字を1つ出すたびにカット**。
- **数字はカウントアップ**で出す（売上の金額などが増えていく）。
- **黒い画面に数字だけ**を出す間（「3」など）。
- **足し算型の演出**：要素が1つずつ増える（チップの横に脳とゲームパッドのアイコンが加わる）。
- 図の説明は、アイコンの下に**黒い札でラベル**。
- **名言カット**：暗い背景に人物、横に引用符付きで大きく。6秒以上止めて余韻。
- **振り返りカット**：過去の場面を3分割で並べ、チェックマークを付けていく。
- 最後は「チャンネル登録」の文字 → 終了画面。

## 人物の大きさ（試作を見てのフィードバックで修正）
- 顔の大きなアップは見づらい（クレヨンのざらざらまで拡大されて粗く見え、点の目も間が抜ける）。
- **基本は腰から上が入る大きさ（画面の高さの5〜6割）。**
- **顔のアップは、驚く・ひらめく瞬間に1〜2秒だけ。**
- 「大きく見せる」のは、人物より**物（花札・ゲーム機・数字・文字）**でやる。
