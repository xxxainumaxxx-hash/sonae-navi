# ロングの台本の作り方

参考：Crayon Capital「How Jeff Bezos Actually Built Amazon」（約20分・英語）を Claude in Chrome で分析した結果から（2本目の分析が届いたら追記する）。

## 1. つかみ（最初の20秒）
- **結果を先に、数字の落差で見せる。** 例：「中古車の助手席で書いた事業計画が、30年後に1分で120万ドルを稼ぐ」
- そのあと**謎を1つ**置いて引っぱる（例：「規制当局が来たとき、彼は姿を消した」）。
- 20秒すぎに**時間を巻き戻して**、物語の始まりへ。

## 2. 章立て
- **4章前後に分ける**（10分なら1章あたり2〜3分）。時系列の三幕構成＋締め。
- 章の頭に**章タイトル**（黒い背景に手書き風の白い文字、約2秒）。
- **各章の最後に「次の章へつなぐ一文」**を入れる（例：「だが、ここから話はもっと危うくなる」）。

## 3. 伏線と回収
- 第1章で**伏線**を置き、**最後に回収**して締める。
  - 参考動画：高校の卒業スピーチで語った「宇宙」の夢 → 最後に「Amazonは目的ではなく、宇宙へ行くための発射台だった」。
- 最後は「これで終わりではない」という**余韻**を残す。

## 4. 文の長さとテンポ
- **1文は短く**（英語で平均約10語）。短い文を重ねてテンポを出す。
- 話す速さは、冒頭と最後が一番速く、中盤は少しゆっくり。
  - 参考動画は英語で毎分約155語（冒頭・最後は約170語）。
  - このチャンネルの声（1.35倍速）は約430字/分で、日本語としてはかなり速め。参考のテンポに近い。
- **重くなりすぎないよう、ところどころに軽い皮肉やユーモアを1行**入れる（例：「深夜3時に、光る庭の小人を600個ワンクリックで買える」）。

## 5. 画面の文字は「強調したい言葉だけ」
- 字幕とは別に、**数字・地名・名前だけ**を絵の一部として出す（1文字ずつ打たれて出る）。
- セリフは**吹き出し**で人物の近くに出す。
- 要点は**丸で囲む**、年号は**付箋**に書く、地名は**地図の札とピン**で順番に出す。
