# ショートの作り方ルール

縦型（1080×1920）。`episodes/s??-*.mjs` に `format: 'short'` を付けると、この形で描き出される。

## 1. 冒頭1秒で「見る理由」
- あいさつ・前置きは禁止（×「こんにちは」「〜って知ってますか？」）。
- **1〜2行目で「何の話か」（会社名・商品名）をはっきり言う。** ×「白黒が、カラーに圧勝した」（何の白黒？）→ ○「白黒のゲームボーイが、カラーに圧勝した」
- **理由は具体的な数字で言う。** ×「電池が長持ち」→ ○「電池4本で約30時間」。比べる相手も名前を出す（×ライバル機 → ○セガのゲームギア）。
- **1行目は結論かオチ**（○「白黒が、カラーに圧勝した」）。
- **最初のコマから絵が出ている**こと。何もない画面から始めない。
- **上部の固定テロップ**（`meta.telop`）で、音を消していても何の話か分かるようにする。全編で同じ文言を出し続ける。

## 2. 伝えることは1つ、間はゼロ
- 1本＝驚きの事実1つ。補足や前置きは入れない（それはロングでやる）。
- 長さは**15〜25秒**。ナレーションは**120〜200字**が目安。
- **字幕1枚は15文字以内**（2行になると、絵や看板とかぶって読みにくい）。長い文は2つに分ける。
- 声は1本の `01.mp3` で録る。**0.3秒以上の無音は自動でカット**される（`animate.mjs`）。
- 前後の「間」も、自動でほぼゼロになる。

## 3. ループ構造
- **最後のセリフが、1行目にそのままつながる**ように書く。
  - 例：最後「たったひとつの、ひまつぶし。」→ 最初「のびる手のおもちゃが、任天堂を救った。」
- **最後のコマの絵と、最初のコマの絵を近い構図にする**（2周目に入ったことに気づかせない）。
- **最後のセリフも、それだけで自然な一言にする。** ループのために「〜したのは…」で1行目へ無理やりつなげない。
  - ×「そして任天堂がやったのは…」→「ゲーム機を、おもちゃとして売った。」（「やったのは、売った」で文法がおかしい）
  - ○「任天堂の作戦は、たったひとつ。」→「ゲーム機を、おもちゃとして売った。」
- **1行目と最後のセリフで、同じ言葉をくり返さない**（2周目でつながったときに、言葉がかぶって聞こえる）。

## 4. コメント欄を開かせる
- 終盤に、**意見が割れる問いかけ**を入れる（「あなたならどっちを買う？」）。
- 絵のすみに、**ちょっとした違和感のある小ネタ**を1つ仕込む（例：背景のネコがこっそりゲームしている）。
  - ⚠ **事実の間違いをわざと入れるのは禁止**。信頼を失い、訂正のコメントだらけになる。仕込むのは絵の遊びだけにする。

## 字幕・配置
- 固定テロップ：上から150px（スマホの上部アイコンを避ける）。
- 字幕：下から560px（いいね・コメントボタンや説明文を避ける）。
- 絵の主役は、だいたい y=380〜1300 の間に置く。

## 公開後のチェック
- アナリティクスで、**「視聴した割合（スワイプされなかった割合）」**と**「平均再生率」**を見る。
  - スワイプされた割合が高い → 冒頭1秒（1行目とテロップ）を直す
  - 再生率が低い → テンポと尺を直す（もっと短く、15〜20秒に）
